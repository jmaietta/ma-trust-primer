# Homeowner

A mobile-friendly primer on personal trusts, estate planning, and homeownership for a **75-year-old, unmarried Massachusetts resident who lives alone and owns the home alone**.

The guide explains common trust types and their tradeoffs, with particular attention to retaining access to assets, planning for long-term care, and passing a home to heirs.

## Open the primer

Download [`Massachusetts_Personal_Trusts_Primer.html`](Massachusetts_Personal_Trusts_Primer.html) and open it in a web browser. No installation, build process, or server is required.

GitHub’s file view displays the HTML source. To read the formatted guide, open the downloaded file or publish it with GitHub Pages.

## What it covers

- Revocable living and irrevocable MassHealth-planning trusts.
- Testamentary, special-needs, spendthrift, and nominee realty trusts.
- Specialized insurance, residence, charitable, and burial trusts.
- Massachusetts homestead protection and sole homeownership.
- Massachusetts and federal estate taxes, inheritance, and capital-gains basis.
- Trust administration and tax considerations at death.
- MassHealth transfer rules and estate recovery.
- Planning for incapacity and choosing decision-makers when living alone.
- Documents and questions to bring to an estate-planning attorney.

Sources are linked alongside the relevant explanations in the guide.

## Reading features

- Responsive layout with large text and mobile comparison cards.
- Expandable descriptions of the different trust types.
- A “Jump to a topic” menu that scrolls with the page.
- Navy, sage, and gold styling.
- Print styles and a small script that expands trust descriptions for printing.

Use your browser’s **Print** command to print the guide or save it as a PDF. Check the print preview to confirm that all desired sections are visible.

## Optional: publish with GitHub Pages

1. Upload both files to the repository’s root directory.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the branch containing the files and the **/ (root)** folder, then save.
5. After deployment, open the published site and append `Massachusetts_Personal_Trusts_Primer.html` to its base URL to view the guide.

To make the primer the site’s home page, rename the HTML file to `index.html` before publishing and update the filename references in this README.

GitHub Pages availability depends on the repository’s visibility and account plan. See [GitHub’s Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Updating the guide

Edit the HTML file directly. Keep the title **Homeowner** and the stated homeowner profile consistent throughout the document.

When changing legal or tax content:

- Verify the applicable rules against current Massachusetts and federal sources.
- Update the guide’s displayed date and affected citations.
- Distinguish MassHealth eligibility from estate recovery, and probate avoidance from estate-tax treatment.
- Preserve qualifications and exceptions when shortening text for mobile reading.

After editing, check phone and desktop layouts, topic links, expandable sections, and print output. The topic menu should remain non-sticky, and comparison tables should become cards on narrow screens.

## Scope and currency

The guide is dated **September 12, 2026**. It is an educational reference, not a trust instrument, individualized estate plan, or legal or tax opinion. It is not automatically updated.

Before creating a trust, transferring a deed, making gifts, or applying for benefits, have a Massachusetts estate-planning attorney with MassHealth experience review the person’s circumstances and coordinate with a tax adviser.

The guide assumes the homeowner is currently unmarried. It does not assume that the person has never been married; prior divorce documents, a deceased spouse’s estate, or existing trusts may require separate review.
